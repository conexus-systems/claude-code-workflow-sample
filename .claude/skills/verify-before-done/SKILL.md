# Verify before done

Before you say a task is done:
1. Run the full check command from CLAUDE.md.
2. Re-read the acceptance criteria and confirm each one against output you saw.
3. Report: what you ran, what passed, what failed, what you did not check.

If a check fails, fix it or say plainly that it still fails. Never write "should work".
